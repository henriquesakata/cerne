## External sources (provenance)

The moment an external source (article, RFC, vendor/API doc, spec) **shapes** a feature, decision, or fix, register it — as you use it, **without waiting to be asked** — instead of leaving a bare URL in prose. Register **only the sources that actually informed the outcome**: a dead-end you opened and discarded is not a reference. If a URL is worth citing in the doc it is worth a `cerne reference`; if it is not, don't leave it as bare prose either.

```
cerne reference new "<title>" --url <url> --informs F-NNNN,D-NNNN [--facet <f>] [--component <c>] [--file <summary> | stdin]
```

It is marked external, its content is indexed (so `cerne ask` cites it), and `--informs` backlinks it to the entity it motivated.

References carry the **same two tag axes as notes** — `--facet` (the closed `infra`/`code`/`data`/`process`/`auth` set; an invalid facet aborts before any write) and `--component` (open, slug-normalized) — and they fold into the FTS the same way, so `cerne search`/`ask` find a reference by its tag. List and filter them with `cerne reference list [--facet <f>] [--component <c>] [--all] [--json]` — the **only** listing for references (AND across axes; `--all` includes superseded; `--json` for machine reads). Legacy references predate tags, so a `--facet` filter over them returns empty with a guidance message. Re-tag a current reference in place with `cerne reference retag R-NNNN --facet <f> --component <c>` (like notes/decisions) — it sets only the axis you pass (`--facet ""` clears that axis), preserves url/informs/body, and never makes the reference obsolete. Retire one with **`cerne reference retire R-NNNN --reason "…"`** (reason required) — a duplicate or a source that no longer holds moves from `current` to `obsolete`, leaving the current state but staying reachable via `reference list --all` and search as history; once it is obsolete, a new reference with the same URL can be registered. Source → idea → feature (F-0389): `--informs I-…` ties a source to an idea, `idea promote` carries the link to the new feature (keeping the `I-`), and `cerne reference link R-… --informs F-… [--unlink <ids>]` adds or removes targets later; `cerne show I-…` lists the sources.
